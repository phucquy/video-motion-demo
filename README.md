# Video Motion: demo

Video motion graphics ngắn, khung dọc 9:16, dựng bằng Claude và [HyperFrames](https://github.com/heygen-com/hyperframes). Hình, chuyển động và âm thanh đều làm bằng code, không dùng ảnh hay nhạc có sẵn.

Repo này chỉ chứa video thành phẩm. Mã nguồn để riêng.

## Sóng lặng (10 giây)

Tranh thủy mặc: núi nhiều lớp, mặt trời đỏ, con thuyền trôi trong sương. Âm thanh tự tổng hợp, khớp từng chuyển động.
